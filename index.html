🔗 DMSS Device Connection

DMSS QR Code দিয়ে ডিভাইস শেয়ার করার সুবিধা আছে। তবে DMSS-এর sharing QR স্ক্যান করলেই এই ওয়েবসাইট ভিডিও অ্যাক্সেস পাবে না।

DMSS-এর সহজ Device Sharing পদ্ধতি:
১. যে ফোনে আপনার DMSS ক্যামেরা যুক্ত আছে, সেখানে DMSS খুলুন।
২. Devices তালিকায় ক্যামেরা/DVR-এর পাশের তিন ডট বা Device Details খুলুন।
৩. Device Sharing নির্বাচন করুন।
৪. যাকে শেয়ার করবেন তার DMSS account অথবা তার DMSS QR Code ব্যবহার করুন।
৫. প্রয়োজনীয় permission নির্বাচন করে Share/OK দিন।

মনে রাখবেন: এটি অন্য DMSS অ্যাকাউন্টকে DMSS-এর ভেতরে ক্যামেরা দেখার অনুমতি দেয়; তৃতীয় পক্ষের ওয়েবসাইটে সরাসরি ভিডিও API দেয় না।

ওয়েবসাইটে লাইভ ভিডিও আনতে DVR/NVR-এর RTSP/ONVIF বা Dahua-এর অনুমোদিত integration এবং server-side video gateway লাগবে।
